Extrator de Vídeos em Python

Interface gráfica em Tkinter que utiliza yt-dlp e FFmpeg para automatizar o download e corte de clipes para edição de vídeo.

Sobre o Projeto

Este projeto foi desenvolvido para otimizar o fluxo de trabalho na edição de vídeos (DaVinci Resolve e CapCut), permitindo baixar e recortar trechos específicos de vídeos diretamente por uma interface gráfica intuitiva.

Construído em Python com Tkinter, o aplicativo executa comandos do yt-dlp e do FFmpeg de forma automatizada, evitando a necessidade de baixar arquivos inteiros ou utilizar linhas de comando manualmente a cada corte.

Tecnologias Utilizadas

Python
Tkinter (GUI)
yt-dlp
FFmpeg
